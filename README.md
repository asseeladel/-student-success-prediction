# مشروع التنبؤ بنجاح الطالب أكاديميًا

مشروع تعليمي متكامل يستخدم KNN للتنبؤ بنجاح الطالب اعتمادًا على:
- الحضور
- الدرجات
- الواجبات
- المشاركة

## التشغيل
1. ثبّت Python 3.10 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   `pip install -r requirements.txt`
4. شغّل:
   `python app.py`
5. افتح المتصفح على:
   `http://127.0.0.1:5000`

## مكونات المشروع
- `app.py`: التطبيق والواجهة الخلفية والتنبؤ والإحصائيات.
- `data/students.csv`: بيانات تدريب تجريبية مولدة للمشروع.
- `models/`: النموذج المدرب، ويتم إنشاؤه تلقائيًا عند أول تشغيل.
- `templates/index.html`: الواجهة الكاملة.
- `static/style.css`: التصميم.
